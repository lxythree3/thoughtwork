# 盘龙城遗址博物院三展厅导览

一个面向思政实践展示的互动网页，以盘龙城遗址博物院三个展厅为主线，展示馆藏文物及其历史信息。

## 功能

- 三个展厅的馆内平面导览
- 13 项重点展项，其中 4 件经典文物
- 点击文物名称打开详情弹窗
- 展示文物图片、年代、出土信息、尺寸、器物特征和历史价值
- 支持上一件、下一件连续浏览
- 适配桌面、平板和手机

## 本地运行

直接用浏览器打开 `web/index.html`，或在项目根目录运行：

```powershell
python -m http.server 8000 -d web
```

然后访问 `http://localhost:8000`。

## 目录

```text
web/
├── index.html
├── styles.css
├── app.js
└── assets/
```

## 资料与图片

页面资料主要来自盘龙城遗址博物院官网的“盘龙城简介”“基本陈列”和馆藏详情页面，部分经典文物图片来自公开馆藏资料。
