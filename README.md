# 器以载道：盘龙城文物中的生态智慧

根据 PRD 实现的纯静态专题页。项目以六件盘龙城文物为线索，讨论材料获取、能源消耗、治水智慧、资源网络和当代生活选择。

## 页面

- `web/index.html`：自动进入生态专题
- `web/ecology.html`：导语、数据锚点、六件文物卡、研学入口与三题互动
- `web/map.html`：带生态图层开关的馆内与遗址联动地图
- `web/downloads/field-card.pdf`：A4 单页研学寻访卡

## 交互

- 文物卡三标签页切换（器物 / 生态视角 / 当代回响），支持方向键
- 文物图片灯箱，支持左右切换与方向键翻看
- 滚动进度条、区块滚动显现、导航随滚动高亮
- 关键数据数字滚动动画
- 学术可靠性说明浮层
- 文物卡片与地图点位互跳
- 地图生态图层开关
- 地图点位摘要与全文跳转
- 三题生态足迹问答，结果只保存在当前页面
- 桌面和移动端响应式布局

## 本地运行

直接打开 `web/index.html`，或在项目根目录运行：

```powershell
python -m http.server 8000 -d web
```

然后访问 `http://localhost:8000`。

## 数据与素材

- 六件文物正文位于 `web/data/artifacts.js`
- 导语与三个数据锚点位于 `web/data/intro.js`
- 问卷结果映射位于 `web/data/quizResults.js`
- 生态地图点位位于 `web/data/mapPoints.js`

音频目录尚未提供 PRD 中的六条音轨，页面已移除“听讲解”占位按钮。排水管道与兽面纹牌形饰使用标注清楚的视觉示意，不冒充器物实拍。
